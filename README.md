# Paesaggi in campo

Applicazione web progressiva (PWA) di supporto alle escursioni del corso «Analisi e interpretazione dei paesaggi naturali» (DiSSGeA, Università di Padova): valle del Vajont e Carso Classico.

Sito statico senza back-end: carta Leaflet su tessere OpenTopoMap/OpenStreetMap, overlay GeoJSON schematici, geolocalizzazione, uso offline tramite service worker. Testi e figure provengono dalle guide dell'escursione (A. Bondesan); le fonti sono indicate in ogni didascalia.
